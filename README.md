# homebrew-tap

Homebrew formulae for wilbeibi tools. goreleaser publishes here on catchup releases.

Formulae live at the tap root, not in a `Formula/` subdirectory. Homebrew
ignores the root once that directory exists, so adding one hides catchup.

```
brew install wilbeibi/tap/catchup
brew install wilbeibi/tap/gitshots
```
